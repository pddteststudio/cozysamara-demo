# kozy. — демонстрационный сайт химчистки мебели в Самаре

Полноценный **адаптивный одностраничный сайт** с оригинальной векторной графикой, интерактивным сравнением и рабочей формой подготовки заявки. Создан как **независимый, неофициальный концепт** для потенциального предложения компании из сообщества [cozysamara](https://vk.com/cozysamara).

**Связь с компанией**: https://vk.me/cozysamara · +7 (927) 700-21-23. Подтвердите актуальность контактов перед использованием в официальном проекте. Автор проекта: [@milmak11](https://t.me/milmak11).

## Запуск

Никаких установок, пакетных менеджеров и серверной части нет.

**Быстрый просмотр:** откройте `preview-offline.html` двойным щелчком. Все стили, JS и оригинальные SVG уже встроены в этот файл. Для работы сайта интернет не нужен; внешние VK-ссылки, естественно, требуют сети.

**Исходный сайт:** откройте `index.html` либо из корня папки запустите:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Публикация на Vercel

1. Распакуйте архив и поместите **содержимое** папки `Kozy_Samara_Website_Vercel` в GitHub-репозиторий, чтобы `index.html` находился в корне.
2. В Vercel: **Add New → Project → Import Git Repository**.
3. **Framework Preset: Other**. Build Command: **отключена / пустая**. Output Directory: оставьте пустой — статические файлы уже в корне.
4. Выполните Deploy.

В качестве адреса можно попробовать `cozysamara-demo.vercel.app` (наличие свободного домена не проверялось).

## Что реализовано

- Уникальная тёплая дизайн-система: молочный, пудровый, голубой и сливовый; крупная типографика, свободное пространство, минимум декоративных рамок.
- **12 авторских SVG-изображений**: интерьер с диваном, кресло, примеры загрязнений, сравнение, сцены фотозаявки и контактов, favicon; отдельные иконки также в SVG.
- Плавные анимации при наведении и прокрутке; поддержка `prefers-reduced-motion`.
- Слайдер сравнения двух **демонстрационных иллюстраций** состояния дивана (не реальные фото компании).
- Два кейса из публичных описаний работ за **6 и 10 ноября 2026 года** (воск и чернила; жёлтые пятна на кухонном диване). Иллюстрации кейсов не являются изображениями реальных заказов.
- Каталог услуг с переходом к соответствующему типу мебели в форме оценки.
- Рабочая форма: выбор мебели, форма дивана, количество от 1 до 8, тип обивки, несколько типов загрязнений, место работ, комментарий до 600 символов.
- **До трёх фото** JPG/PNG/WebP до **8 МБ каждое**: локальный предпросмотр и удаление. Фотографии остаются на устройстве и никуда не загружаются.
- Живое резюме обращения, копирование полного текста и переход в сообщения VK. **Никакие заявки сайт сам не отправляет.**
- Адаптивное меню, мобильная фиксированная кнопка оценки, FAQ, этапы, объяснение факторов стоимости, контакты и телефон.
- Небольшая рамка `Разработчик @milmak11` в футере.
- Демонстрационный баннер + `noindex` и `robots.txt`, чтобы не выдавать сайт за официальный ресурс.

## Важное перед коммерческим использованием

- **Нет подтверждённого прайса**. Сайт не придумывает цены, гарантии, срок чистки или обязательный перечень услуг.
- Данные о работах в ноябре взяты из публичных описаний компании; **фото реальных заказов не использованы**, а иллюстрации честно обозначены как демонстрационные.
- Услуги помимо химчистки диванов приведены как заявленные в описании сообщества и требуют подтверждения у владельца.
- Адрес, дополнительные мессенджеры, юридические реквизиты и реальные отзывы не добавлены без подтверждения.
- Перед размещением от имени компании нужно получить её согласие, актуальные контакты, подтверждённые условия работы и, желательно, разрешённые фотографии «до/после».
- Для настоящего приёма заявок и фотографий потребуется отдельная интеграция, уведомления и политика обработки персональных данных. Здесь данные обрабатываются локально в браузере, а в VK переход осуществляется вручную.
- Удаление `noindex` допустимо после согласования с владельцем и запуска официального сайта.

Структура HTML, локальные пути, ссылки-якоря, SVG и синтаксис CSS проверены.
